feat(tui): live parallel-batch indicator during pending window (#516)

Phase 2 of the concurrent-batch visibility feature. Phase 1 (already
shipped) adds ∥i/N badges on completed tool rows. Phase 2 adds a live
[×N] badge on every in-flight row while a parallel wave is still running.

## What changed

### New `tool.batch.start` ProviderEvent / `batch-start` OutputEvent
- `src/agent/provider.ts` — new `type: 'tool.batch.start'` member on the
  `ProviderEvent` union. Carries `batchSize` (≥ 2) and `toolUseIds[]`.
- `src/agent/types/session-types.ts` — mirrors as `type: 'batch-start'`
  on `OutputEvent` with the same fields.

### Dispatcher emits batch-start events
- `src/agent/tools/dispatcher.batch-process.ts` — new `batchEventSink?`
  callback on `BatchExecDeps`. `runConcurrentBatch` calls the sink at the
  top of each wave before any handler fires.
- `src/agent/tools/dispatcher.ts` — new private `pendingBatchEvents[]`
  accumulates sink calls. New public `drainBatchEvents()` clears the buffer.
- `src/agent/providers/anthropic-direct/types.ts` — added
  `drainBatchEvents?()` to `ToolDispatcherLike`.

### Provider loops yield batch-start events
- `src/agent/providers/anthropic-direct/loop/tool-dispatch.ts` — drains
  and yields `tool.batch.start` events after executeBatch returns.
- `src/agent/providers/openai-compatible/query/dispatch-append.ts` — same.
- `src/agent/session/stream-consumer.ts` — maps to `batch-start` OutputEvent.

### TUI live overlay
- `src/cli/commands/interactive/tool-lane-format.ts` — new
  `pendingBatchBadge(toolUseId, pendingBatch)` → `[×N]` (dim, × glyph).
- `src/cli/commands/interactive/tool-lane.ts` — `notifyBatchStart`,
  lazy clear in `addResult`, badge in `getOverlay` for in-flight rows.
- `src/cli/_lib/stream-renderer-orchestrator.ts` — handles `batch-start`.
- `src/cli/_lib/stream-renderer-subagent.ts` — no-op for subagent path.

## Tests (18 new tests)
- `dispatcher.test.ts` — 7 tests for `drainBatchEvents`
- `tool-lane-format.test.ts` — 5 tests for `pendingBatchBadge`
- `tool-lane-batch-start.test.ts` — 6 tests for `ToolLane.notifyBatchStart`

Closes #516 Phase 2
