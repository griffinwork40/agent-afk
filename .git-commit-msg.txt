fix(whatif): disable context-injecting hooks in episodes so arms see identical context

In --verify mode, episode child sessions run in a baseline and candidate arm.
Previously, SessionStart and UserPromptSubmit config/plugin hooks were allowed
to run in episodes. Hooks such as pattern-card surfacers inject text ranked by
cwd/branch overlap and recency logs, and cwd/home differ per arm, so the first
user message could differ between arms — confounding every delta measurement
(surfaced as a non-empty `structural.userMessageDiff`).

Changes:
- `src/config/env.whatif.ts`: add `AFK_WHATIF_KEEP_CONTEXT_HOOKS` (boolean,
  default empty). When falsy (default), all config/plugin hooks are disabled in
  episode mode. When truthy (1/true/yes/on), restores pre-fix behaviour for
  tests that specifically exercise context-injecting hooks.
- `src/agent/whatif-episode-gate.ts`: export `keepContextHooksInEpisode()`,
  using the same 1|true|yes|on idiom as `projectMcpOptIn`.
- `src/agent/hooks/config-bridge.ts`: in episode mode, unless the opt-in is
  set, skip ALL hook registration (not just side-effect events). Emits one
  `console.warn` naming disabled hooks so the operator can diagnose.
- `src/whatif/run.limits.ts`: add `hookIsolationLimits()` — returns a Limits
  bullet noting that context-injecting hooks were disabled in episodes, plus a
  second bullet if `structural.userMessageDiff` is non-empty (arms still
  diverged, so the delta may be confounded).
- `src/whatif/run.ts`: wire `hookIsolationLimits` into the verified-run limits
  array alongside existing shortfall limits.
- `docs/env-registry.{json,md}`: regenerated (202 vars; pnpm scan:env).
- Tests: updated `config-bridge.test.ts` episode suite for new default (all
  events disabled), added opt-in and cwd-dependent-hook tests. New
  `hookIsolationLimits` tests in `run.limits.test.ts`.

Note: `default-hook-registry.ts` `createPlaceholderPreventHook` (registered on
SessionStart) is a static instruction hook that does not read cwd or recency
state — it is not part of this bug and was left untouched.

Closes #2426
