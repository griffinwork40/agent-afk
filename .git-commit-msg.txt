Addresses code follow-up checklist items from #3545.

## #3373 — insights/defects CLI

- insights.ts: replace `parseInt(x) || 30` with NaN-aware pattern so
  `--days 0` floors to 1 instead of silently becoming 30.
- defects.ts: emit ledger-truncation warning on stderr in `--json` mode
  so scripted consumers get a signal when data is truncated.
- defects.test.ts: replace local two-arm `stripAnsi` with
  `stripEscapeSequences` from `src/utils/terminal-sanitize.ts`; add
  tests for `--days -1`, `--top -5`, and `--json` + ledgerTruncated.

## #3306 — telegram/media-download.ts security hardening

- Add `malformed-url` status to `DownloadResult` (was folded into
  `ssrf-rejected`); update all switch callers (media-helpers, document).
- Add `url.username === '' && url.password === ''` check to the SSRF
  predicate (SI-2a: reject embedded credentials).
- Add query-param token strip to both `safeMessage` redaction paths as
  defence in depth.
- Update existing malformed-URL test to expect `malformed-url`; add
  credential-embed SSRF test.

## #3306/#3344 — fix upward dependency (media-download -> handler layer)

- Extract `readResponseBytesWithLimit` + `LimitedReadResult` from
  `handlers/message.media-helpers.ts` into new sibling utility
  `src/telegram/response-body-reader.ts`.
- `media-download.ts` now imports from the sibling (same layer).
- `message.media-helpers.ts` re-exports both so existing callers are
  unaffected.

## #3313 — version-skew / daemon sidecar

- version-skew.ts: `isValidSidecar` validates version strings against a
  loose semver regex instead of accepting any non-empty string.
- version-skew.ts: `writeServiceStartupSidecar` returns boolean so
  callers can log on failure.
- daemon.action.ts: log at warn when sidecar write fails; extracted into
  `recordDaemonStartup()` helper to stay under the 200-line ceiling.
- telegram/entry.ts: log at warn when sidecar write fails; extracted
  into `recordTelegramStartup()` helper; added explanatory comment on
  why `daemonVersion` (from disk) is used instead of `getVersion()`.
