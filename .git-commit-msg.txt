feat(#4266): allow continuing worktree-isolated subagent chains

Previously, chains minted with `isolation: "worktree"` were refused
fail-closed at continuation time ("not supported (v1)"). This commit
lifts that restriction:

- When an isolated child ends and the chain is still continuable, the
  worktree is git-locked (reason names the chain id) and its path is
  stored on the chain record instead of being torn down.
- The next continuation link runs with `cwd` overridden to that kept
  worktree, so it sees uncommitted edits from the previous run.
- When the chain can no longer be continued (limits exhausted, evicted
  from the 256-chain cap via `onEvict`, or session end via `dispose()`),
  the lock is released and the tree is handed back to the normal sweep
  (remove if clean, preserve-and-relock if dirty / commits-ahead).

Seam changes (contained to continuation + isolation-teardown seams):
- `continuation-registry.ts`: add `isolatedWorktreePath` to `ChainRecord`;
  add `setIsolatedWorktreePath` / `clearIsolatedWorktreePath`; add
  `onEvict?: ChainEvictCallback` and `dispose()` for lifecycle cleanup.
- `continuation-guards.ts`: remove the `isolation: "worktree"` refusal
  from `checkContinuationOverrides`.
- `continuation-dispatch.ts`: remove `isolation !== 'worktree'` exclusion
  from `isContinuable`; export `isContinuableChain` for the executor.
- `continuation-run.ts`: `continuationInput` uses the stored worktree
  path as cwd for isolated chains.
- `foreground-promotion.ts`: `RunForegroundArgs` gains `onIsolationTeardown`
  hook; finally calls `runIsolationTeardown` (extracted helper) which
  defers to the hook or falls through to normal teardown.
- `subagent-executor.execute-once.ts`: builds the hook via
  `buildIsolationTeardownHook` (continuation-worktree.ts).
- `wire-executors.ts`: wires `onEvict` and `dispose` on the registry.
- New file: `continuation-worktree.ts` — `keepWorktreeForChain`,
  `releaseChainWorktree`, `buildIsolationTeardownHook`.
- Docs: update `docs/subagent-continuation.md` (remove worktree from
  v1 limitations; add "Worktree-isolated chains" section).

Tests: 5 new deterministic tests in `continuation-worktree.test.ts`
(no real model calls, git mocked); updated 4 existing tests that
asserted the old v1 refusal behavior.

Closes #4266
