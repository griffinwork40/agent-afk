---
title: "Use bundled workflow skills"
description: "Choose from the public SKILL.md workflows shipped with AFK."
---

AFK ships the `awa-bundled` plugin with public workflow skills. Invoke one by typing its slash name in the REPL, or ask the agent to use it. Check `/skills` for the skills currently discovered in your installation; these workflows complement the core skills.

## Choose a workflow

| Skill | Use it when |
|---|---|
| `/orient` | You want an end-of-session orientation prompt for a fresh session, with candidate directions rather than a prescribed plan. |
| `/spec` | A loose idea needs a scoped specification before implementation. |
| `/research` | You need external and local evidence together. |
| `/gather` | You need a parallel structure and test map of a code area. |
| `/ground-claim` | You need evidence for a capability claim or runtime wiring. |
| `/diagnose` | A bug or failing test needs independently checked root-cause hypotheses. |
| `/review` | You need read-only review of a diff, commit, or PR. |
| `/fix-pr` | A PR has actionable reviewer feedback or red CI. It triages feedback and can push validated fixes; supply a PR number or URL. |
| `/polish` | You want an artifact refined against explicit criteria with an evaluator and generator loop. |
| `/simplify` | You want a read-only complexity reduction plan; request apply mode deliberately. |
| `/refactor` | A structural change spans multiple sites and needs layered verification. |
| `/ship` | Verified local changes are ready for commit, push, and PR. |
| `/automate` | You want to set up a scheduled task with Telegram results; invoke it explicitly. |

`/fix-pr` checks GitHub authentication and PR branch access before writing, and does not force-push. `/review` is read-only. `/ship` and `/fix-pr` may change local and remote state, so inspect their plans and use only when you intend those effects.

## Reasoning and verification helpers

| Skill | Purpose |
|---|---|
| `/ground-state` | Reconnaissance across git state, infrastructure, and memory before substantial implementation. |
| `/parallelize` | Turn a plan into dependency-aware parallel waves. |
| `/devils-advocate` | Generate alternative approaches before committing to a plan. |
| `/shadow-verify` | Independently recheck consequential subagent claims. |
| `/false-completion-gate` | Reconcile a claimed completed write against execution receipts and fresh artifact read-back. |
| `/contract` | Shared structured input and output convention for orchestration skills. |

Some of these are invoked automatically by AFK's task lifecycle, but explicit slash invocation is also available. `/false-completion-gate` checks state-changing completion claims; it is not a replacement for running tests. `/contract` is primarily a helper for other skills. The shipped collection is visible in `src/bundled-plugins/awa-bundled/skills/`; do not assume plugins installed separately are bundled.
