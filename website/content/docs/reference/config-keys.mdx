These keys are accepted by the configuration mutation API. Agent tier keys are nonsecret behavioural settings that the agent may change. Human tier keys control identity, trust, routing, or safety and require the human CLI; the agent configuration tool refuses them. Keys are sorted by dotted path.

See [editing configuration](/configuration/editing-config) for file locations and precedence.
