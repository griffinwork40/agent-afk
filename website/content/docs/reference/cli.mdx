Usage: `afk [options] [command]`

## `afk improve eval-cases list`

List all eval-cases, newest first

Usage: `afk improve eval-cases list [options]`

Guide: [self-improvement](/guides/self-improvement)

### Options

| Flags | Description | Default |
| --- | --- | --- |
| `--card <slug>` | Filter by card slug |  |
| `--pattern <name>` | Filter by pattern (one of: repeated-tool-use, subagent-block, closure-anomaly, tool-failure-density, subagent-read-denial) |  |
| `--status <state>` | Filter by status (one of: draft, approved, rejected, superseded) |  |
| `--triage` | Show only draft eval-cases, sorted oldest-first by age (highest-priority first for human review) | `false` |
| `--json` | Emit JSON instead of a table | `false` |
| `-h, --help` | display help for command |  |

## `afk improve eval-run`

Run the smallest deterministic validation contract for an eval-case's pattern.   Validates guardrails (no LLM, no patch/apply). Known contracts: repeat-loop-circuit-breaker, subagent-hook-block-detector, tool-failure-density-enabled, closure-abort-recovery-hint.

Usage: `afk improve eval-run [options] <evalCaseIdOrCardSlug>`

Guide: [self-improvement](/guides/self-improvement)

### Arguments

| Argument | Description | Default |
| --- | --- | --- |
| `<evalCaseIdOrCardSlug>` |  |  |

### Options

| Flags | Description | Default |
| --- | --- | --- |
| `--id <override>` | Override the auto-generated eval-run id |  |
| `--json` | Emit the eval-run JSON to stdout (still writes to disk) | `false` |
| `--no-write` | Run and render without persisting to disk (preview mode) |  |
| `-h, --help` | display help for command |  |

Usage: `afk transcript [options] [command]`

Guide: [observability](/guides/observability)

### Options

| Flags | Description | Default |
| --- | --- | --- |
| `-h, --help` | display help for command |  |

### Subcommands

| Command | Description |
| --- | --- |
| `reindex` | Build (or rebuild) the FTS5 full-text index from all transcript files on disk. Safe to run repeatedly — replaces the index atomically. |
| `search` | Search indexed transcripts via FTS5 full-text search. Supports FTS5 syntax: "exact phrase", term*, AND, OR. Run `afk transcript reindex` first to build the index. |

## `afk acp`

Start an Agent Client Protocol (ACP) JSON-RPC 2.0 server over stdio (compatible with Zed, JetBrains, and other ACP clients)

Usage: `afk acp [options]`

### Options

| Flags | Description | Default |
| --- | --- | --- |
| `-m, --model <model>` | model to use for sessions (default: configured default) |  |
| `--max-turns <n>` | maximum agent turns per prompt (default: 10) | `"10"` |
| `--dangerously-skip-permissions` | Force bypass mode: skip all permission prompts for all sessions created by this server |  |
| `-h, --help` | display help for command |  |
