Agent AFK (`afk`) is an open source AI agent runtime that runs as its own process. You can ask it to inspect a project, edit files, run commands, and delegate work, then review the results in an interactive session or an unattended workflow.

## Who it's for

* **Developers** who want help understanding a codebase, making changes, and checking the result.
* **Engineers automating recurring work** who need scripted runs, scheduled tasks, or a persistent daemon.
* **People supervising longer tasks** who want to check progress through Telegram or a web interface instead of staying at a terminal.

You choose the model provider and configure the tools, permissions, and instructions available to the agent. Start with an interactive session before setting up unattended work.

## Know what you are granting

The agent can execute commands and change files with your account's access. A new CLI installation starts in `bypassPermissions` mode, which disables path containment and path-approval prompts. Use `--permission-mode default` to enable path approvals, and read [Safety](/concepts/safety) before allowing unattended work.

Configuration, saved sessions, and local runtime artifacts normally live under `~/.afk/`. Model requests go to the provider you configure, and enabled tools or integrations can send data to other services. Review [tool access](/guides/tool-access) and [extensions](/concepts/extensions) when connecting additional capabilities.
