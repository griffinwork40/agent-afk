---
title: "Start from zero"
description: "Open a terminal, install afk, and return to it tomorrow."
---

Use this page if you have never used a terminal. A terminal is an app where you type short text commands to your computer. You do not need to understand every line it prints.

After opening a terminal, continue with [Install afk](/installation).

## macOS

<Steps>
<Step>
### Open Terminal

Press <kbd>Command</kbd> + <kbd>Space</kbd>, type `Terminal`, then press <kbd>Return</kbd>. A window with a line ending in `$` or `%` opens. That is where you type commands.
</Step>
<Step>
### Paste and run a command

Copy a command from these docs. In Terminal, press <kbd>Command</kbd> + <kbd>V</kbd> to paste it, then press <kbd>Return</kbd> to run it.

During installation, npm can print notices about funding, audits, or packages. Those lines are usually informational. Stop and read the message if it says `error` or the command ends without returning to a line where you can type.
</Step>
<Step>
### Leave and return tomorrow

When afk is open, type `/exit` and press <kbd>Return</kbd>. You can also press <kbd>Control</kbd> + <kbd>C</kbd> to interrupt a command. Do not use <kbd>Command</kbd> + <kbd>Q</kbd> unless you want to close every Terminal window.

Tomorrow, open Terminal the same way, then type `afk` to start an interactive session or `afk chat "your question"` for one answer.
</Step>
</Steps>

## Windows

<Steps>
<Step>
### Open Windows Terminal

Open the Start menu, type `Windows Terminal`, then select it. If you do not have Windows Terminal, type `PowerShell` in the Start menu and select **Windows PowerShell**.

The tab title tells you which shell you opened. **PowerShell** or **Windows PowerShell** means you are using native Windows. A title such as **Ubuntu** means you are in WSL2, a Linux environment inside Windows. Follow the matching installation tab.
</Step>
<Step>
### Paste and run a command

Copy a command from these docs. In Windows Terminal, right-click in the window to paste, or press <kbd>Control</kbd> + <kbd>Shift</kbd> + <kbd>V</kbd>. In Windows PowerShell, right-click to paste. Press <kbd>Enter</kbd> to run the command.

During installation, npm can print notices about funding, audits, or packages. Those lines are usually informational. Stop and read the message if it says `error` or the command ends without returning to a line where you can type.
</Step>
<Step>
### Leave and return tomorrow

When afk is open, type `/exit` and press <kbd>Enter</kbd>. You can also press <kbd>Control</kbd> + <kbd>C</kbd> to interrupt a command. Closing the window also ends afk.

Tomorrow, open Windows Terminal or PowerShell again, then type `afk` to start an interactive session or `afk chat "your question"` for one answer.
</Step>
</Steps>

Follow [Install afk](/installation). It tells you which version of Node.js to install and gives the commands to copy into your terminal.
